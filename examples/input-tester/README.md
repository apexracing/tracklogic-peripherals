# 设备库输入测试窗口

此窗口直接使用 `pkg/input.Manager`，与调用方共用输入状态、独立订阅和绑定录入逻辑。
它不修改 TrackLogic 配置，不发送力反馈或设备输出，也不安装驱动。

- 选择控制器后，按住按钮会点亮编号，松开后熄灭。每页显示 64 个按钮。
- 方向帽显示当前方向，键盘区显示当前按住的键与组合。
- “录入绑定”调用库的 `Capture`，完整按下并松开后才成功；等待期间可取消。
- “编辑拦截测试”只在本测试窗口前台拦截方向键、Space、W/A/S/D/F；切换到其他窗口后放行。
- “重新连接”会关闭原输入管理器并创建新管理器，用于验证失败后的恢复。
- 可选 `-log <path>` 记录控制器事件、主动录入的绑定，以及勾选拦截测试且测试窗口在前台时的编辑键。不记录普通键盘输入历史。

在仓库根目录运行：

```powershell
go build -ldflags '-H windowsgui' -o build/TrackLogic.InputTester.exe ./examples/input-tester
```

直接启动生成的 EXE 即可。库在进程内的一条 Go 原生线程读取
`Windows.Gaming.Input.RawGameController` 并监听、拦截键盘，无子进程、额外 DLL 或 GameInput SDK 依赖。

设备枚举成功、窗口正常显示和自动测试通过，都不等同于实机输入通过。
发布前须分别验证按钮与方向帽按下/松开、完整绑定、重连，以及开启拦截后的键盘输入。
